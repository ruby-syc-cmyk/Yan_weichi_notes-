# 雁未迟穿越札记

> **全名：**《雁未迟穿越札记：记本人误穿入古代之后，如何千辛万苦寻觅归返未来之法，并沿途所遇诸事、诸人、诸般见闻悉数杂录》

---

## 📖 简介

**雁未迟**，三十二岁，法医病理学与人类机械运用学双博士，人类学家，196实验室最高级负责人。

2635年3月18日，她正处理一起时空穿越杀人事件受害人的尸检工作。就在对尸体进行生存年代检测时，检测仪骤然发出尖锐警报声。她取下手套，快步进入机控室检查，却在那一刻遭遇突如其来的磁暴魂穿事故——精神被强行拉扯，坠入**公元645年，617号平行时空的炎晋皇宫**。

网文大乱斗，囊括了市面上所有的题材。每种题材都交给雁未迟的法医刀重新切片：

#权谋文？不，是地方士族与中央集权的结构力学分析

#战争文？不，是后勤学、地理学与群体心理学的综合实验

#武侠文？不，是暴力作为生存算法的极端案例

#赛博朋克？不，是技术哲学在古代土壤里的异化生长

#民俗文？不，是仪式人类学的活体记录

#甜宠？Nonono，生物神经放电机制

每一种题材进来，都会被雁未迟的"未来视角"重新编码。 这是单一视角的无限兼容性乱码——一个法医的眼睛，足以解剖整个古代文明。

雁未迟——一个在未来世界孤独研究"肉体意义"的法医，穿越到古代依然孤独（没有人能真正理解她的未来视角）。雁未迟是你的镜像。 她通过探索亲密（性行为作为学术实验）、探索权力（与上官兄弟的博弈）、探索存在（机魂与人魂的融合）观察世界。

道生一，一生二，二生三，三生万物。启！哔——
